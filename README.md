<h1 align="center" style="font-weight: bold;">Aulas de Java</h1>

![java][JAVA_BADGE]

Este repositório contém as aulas e soluções para diversos desafios, na grande maioria das aulas foram desenvolvidas na plataforma Udemy, todos implementados na linguagem Java. Cada pasta representa uma aula em específico para facilitar a compreensão. 
Este projeto é dedicado ao ensino de Java, abordando os conceitos fundamentais da Programação Orientada a Objetos (POO), como herança, encapsulamento e abstração entre outros extras como JPAMaven, JDBC, Exceptions, Try-Catch. As aulas são estruturadas para facilitar o aprendizado, proporcionando exemplos práticos e exercícios.
# Tecnologias utilizadas
### Back end
- Java

### Back end
Pré-requisitos: Java 21, Intellij IDEA.

```bash

# entrar na pasta do projeto back end

# executar o projeto
Importe no Intellij IDEA ou qualquer outro IDE Java.
Execute a aplicação :D
```
